# 字城 GRE City

背一個 GRE 單字，城市就多一棟建築。複習答對，建築就升級成下一種；太久沒複習，建築會褪色、長草。

## 怎麼玩

- **城市**：等角視角的島分成 9 個街區（言談、真偽、褒貶、流變、謹慎、傲謙、繁簡、爭和，還有「散字碼頭」放沒分類的字）。每棟建築就是一個單字，可拖曳、縮放，點建築看它的狀態。
- **複習**：翻卡後自評「忘了／模糊／記得」，馬上看到建築的變化。鍵盤操作：空白鍵翻面，1／2／3 評分，Enter 下一個。
- **字庫**：貼上 CSV 或從試算表複製匯入（欄位 `word, zh, pos, example, district`）。沒填街區的字會依字根和中文意思自動分區，之後也能手動改。這裡也可以下載和還原備份。
- **統計**：各類建築數量、近 14 天紀錄、各街區狀況、最常忘的字，以及每日新字數設定（預設 50）。

## 建築與複習間隔

| 等級 | 建築 | 下次複習 |
| --- | --- | --- |
| 0 | 工地（地基＋鷹架） | 明天 |
| 1 | 斜屋頂小屋 | 1 天 |
| 2 | 連棟屋（煙囪） | 3 天 |
| 3 | 公寓（水塔） | 7 天 |
| 4 | 塔樓（玻璃帷幕） | 21 天 |
| 5 | 金頂地標 | 60 天 |

- 記得：升一級。
- 模糊：等級不變，間隔減半。
- 忘了：拆回地基，同一輪稍後會再出現一次。
- 過了複習日：建築褪色。
- 逾期超過一個間隔：建築長草，必須先答對一次「修復」才能再升級。

## 開發

```bash
npm install
npm run dev      # 本機開發
npm test         # 單元測試
npm run build    # 輸出到 dist/，可直接放上任何靜態網站主機
```

技術：React + Vite + TypeScript。城市用 SVG 繪製，資料存在瀏覽器的 IndexedDB，沒有後端。打包後可當 PWA 安裝到手機。內建 383 個 GRE 高頻字當起始字表。
